# Archived surfaces

AIresearch now prioritises focused research intelligence workflows. The legacy experiments listed
below have been formally archived so visitors land on the new research experience by default.

## Ricktorious commerce demo

- **Status:** Archived and returns HTTP 410 from [`ricktorious.php`](../ricktorious.php) so the legacy
  storefront is no longer exposed on production environments.
- **Reason:** The team is consolidating around knowledge graph search, brief generation, and research
  operations tooling.
- **Code location:** Supporting libraries remain in [`src/Ricktorious/`](../src/Ricktorious/) for
  reference and regression tests. The interactive UI and storefront assets are no longer actively
  maintained.
- **Restoring locally:** Check out an earlier commit in git history prior to the archive notice or
  copy the deprecated frontend from the history of `ricktorious.php` if you need to replay the
  experience in a sandbox.

For any other retired demos or bespoke surfaces, please contact the research platform team at
[support@airesearch.local](mailto:support@airesearch.local).
